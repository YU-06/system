# ADR 0002：科研聚合、任务一致性与记录保留

状态：接受。日期：2026-11-06。仅供科研与教学演示，非医疗器械，不用于临床诊断。

## 决策

- 沿用既有 ABP 分层和自动控制器，不引入独立微服务或直接返回 Entity。五个聚合的公开业务属性为只读，方法保护状态和固定研究范围；结果与实验记录不可变。
- Application.Contracts 使用现有 ABP DTO 类及分页/审计基类，而不是与这些类不兼容的 record 继承；业务时间输出 DateTimeOffset，继承的 ABP 审计时间保持框架协议。
- Job 只允许显式状态机转换，终态不可任意恢复，Failed 最多三次重试；只接受受限失败原因。创建以 RequesterId/IdempotencyKey 唯一，同键不同内容返回冲突，相同内容返回已有任务。
- 所有写入必须拥有父读权限及对应子权限。权限定义在 Contracts，中文/英文资源在 Domain.Shared，通过嵌入虚拟文件清单加载；没有匿名写、默认管理员或前端隐藏式授权。
- 所有实体使用审计、软删和 EF 并发戳。DTO 先检查客户端版本，EF 再处理真实并发写入。新调度与重试更新 Study 调度计数，让 Job 创建与 Study 删除争用同一版本，不能仅依靠一次“没有活动任务”的查询。
- Study 软删除；活动任务阻止归档/删除，终态任务、结果和文件保留以审计。数据库 FK 全部 RESTRICT，无物理级联或自动清理。部分唯一索引只释放已删除 Study 的活动编号/文件切片身份，Job 幂等键及已记录结果不释放。
- 默认模型全局唯一且必须启用；默认切换、Job 成功与结果插入使用显式事务。权重和产物先验证对象存在性/哈希，模型登记不替代 Python 模型加载就绪。
- 分页上限 100，筛选表达式由代码构造，排序使用字段表达式白名单和 Id 稳定次序，不接受动态 LINQ 字符串。
- 文件通过 IObjectStorage，保存系统对象键与计算出的 SHA-256。上传验证 NIfTI 结构/尺寸/载荷和限额，推理数值/仿射及预处理仍由已有 Python 版本实现负责；不把 MRI 写入数据库或审计。
- 结果默认指标为空，模型/实验元数据默认 NotRun；示例和测试全部使用明确的合成制品，不产生真实研究结论。
- PostgreSQL 是生产 provider。SQLite 用于本地真实关系约束与并发测试，专用 PostgreSQL 测试则通过真实迁移创建一次性独立数据库，在 CI 执行。没有连接配置时明确 Skip，不用 SQLite 通过替代 PostgreSQL 验收。
- 按显式要求使用 AutoMapper。ABP 的 14.x 间接依赖有 GHSA-rvv3-g6hj-g44x 高危告警，升级固定 15.1.4，并仅替换配置实例工厂以保留 ABP 配置器及对象映射。未压制审计；生产许可证从环境变量注入，开发测试提示如实记录。

## 后果

领域对象不能通过通用 Update DTO 绕过状态机。保留记录需要持续存储容量与后续清理策略，但避免无意销毁研究追溯材料。PostgreSQL 迁移生成及 SQL/模型校验不等于已在本机应用真实迁移；本机无数据库时测试报告必须保留该限制。
