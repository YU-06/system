# ADR 0006：Angular 科研工作台

状态：Accepted  
适用范围：BraTS 2020、T2-FLAIR、Whole Tumor 科研教学演示

**免责声明：仅供科研与教学演示，非医疗器械，不用于临床诊断，不提供确诊、治疗或预后建议。**

## 决策

- 沿用仓库 Angular Standalone 与严格 TypeScript 约定，使用 ABP 生成的业务代理，不在组件中重复实现 HTTP 客户端。
- 以 study、job、result、model、experiment 五个 feature 组织页面。Study/Job/Model/Experiment 列表支持分页和筛选；Job 状态以有终止条件的轮询更新，组件退出时销毁订阅。
- 页面导航、路由和操作按 ABP Permission 配置显示或拒绝访问；配置不可用时 fail-closed。后端仍独立鉴权。当前前端未提供 OIDC 登录界面。
- 原始影像只在 SPA 内存中保留，缓存有 192 MiB 上限并按最近使用顺序逐出；没有后端原图下载端点，刷新页面或缓存逐出后需重新上传才能查看对应原图。该限制不将影像写入浏览器持久化存储。
- 浏览器对 `.nii/.nii.gz` 执行类型、压缩/解压大小、NIfTI-1 结构、维度、数据类型、空间元数据、有限数值和 SHA-256 初步检查；服务端校验仍是安全边界。
- 结果查看器只有在源影像与预测掩膜的维度及 affine 一致、掩膜为二值时才显示。只提供原图、掩膜、叠加、轮廓、并排模式、透明度、缩放和轴位键盘浏览。
- 只有登记了真实标签且结果包含评价协议、GT 哈希和完整有限指标时才显示 Dice、IoU、Precision、Recall；没有 GT 时明确显示未提供可评价标签，不以 0 代替。
- 计时使用独立标签：模型纯前向的病例总耗时、按轴位层数折算的单层前向平均耗时、预处理、后处理，以及从 Job 请求到完成（包含排队）的端到端耗时。
- UI 中所有用户可见文字使用中文本地化资源，并固定显示科研用途免责声明。

## 后果与限制

- 刷新或内存缓存逐出后，服务器仍能提供已授权结果掩膜，但本阶段没有原图下载接口，因此不能恢复原图叠加；用户需重新上传同一病例。
- 浏览器校验为易用性提示，不替代 API 的类型、大小、空间元数据、权限及内容校验。
- 自动化端到端测试使用合成 NIfTI 和 HTTP fixture，只验证 UI 流程，不代表真实权重推理、后端联调或研究指标。
- 截至本 ADR，未执行真实模型 E2E、OIDC 登录集成、实际 PostgreSQL/对象存储联调；未从替身或合成数据生成论文成绩/趋势图。

实现与验证记录见 [阶段七测试报告](../test-reports/0007-angular-ui.md)。
