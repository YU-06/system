# ADR 0003：可复现的 BraTS 实验协议与测试冻结

状态：Accepted  
适用范围：BraTS 2020 T2-FLAIR、二维轴位 Whole Tumor 二分类分割  

**免责声明：本项目仅供科研与教学演示，不是医疗器械，不用于临床诊断，不提供确诊、治疗或预后建议。**

## 决策

以 [`ml/configs/experiment_protocol.yaml`](../../ml/configs/experiment_protocol.yaml) 作为版本化预注册协议，以 `ml/configs/baseline.yaml` 作为执行配置。U-Net 与仅在跳跃连接增加 Attention Gate 的 Attention U-Net 使用相同患者 split、输入预处理、增强、损失、优化器、学习率、batch size、最大 epoch 和 early stopping。模型对按种子 17、42、2024 配对。自动比较展开后的运行配置；除架构、Gate 开关和运行 ID 外出现任何差异即拒绝。

患者级划分固定为 258/74/37，split manifest 与预处理缓存均校验 SHA-256。验证集和测试集保留完整切片。训练可控制空病灶切片比例，不能由测试集调参或删样本。

## 模型选择、阈值与冻结

训练期逐轮以验证集完整三维重建后的患者宏平均 WT Dice（阈值 0.50）选择最优 checkpoint，并按预注册耐心值早停。最优 checkpoint 的验证报告再按相同患者级指标搜索 0.30 至 0.70（含端点，步长 0.05）；最高分并列时选最接近 0.50 的候选，再并列时选较低阈值。另有固定 0.50 的敏感性模式。两个阈值模式都只读取验证集。

冻结文件及其 SHA-256 sidecar 绑定 Git commit、配置/协议/split/cache/checkpoint/模型权重哈希、模型和预处理版本、种子、运行 ID、阈值、选择模式、验证报告哈希与数据类型。测试入口检查冻结记录完整性、哈希、身份、阈值来源、候选网格、报告患者指标与所选阈值分数一致；缺项、测试来源、合成/真实数据混用或任意哈希不匹配都拒绝执行。测试只能在权重、阈值和超参数冻结后运行。

## 评价口径

- 切片指标：逐二维轴位切片分别计算二分类混淆计数及 Dice、IoU、Precision、Recall；切片宏平均为切片分数的算术平均。
- 患者指标：将预测切片还原为完整三维掩膜后，在单个患者全部体素上合并混淆计数，再计算患者 Dice、IoU、Precision、Recall。
- 患者宏平均：各患者指标的无权算术平均，为患者级主要指标。
- 整体 pooled 指标：把所有患者体素混合累加混淆计数后再计算，仅作辅助汇总，不代替患者宏平均。
- GT 与预测均空时四个指标均定义为 1；恰有一方为空时四个指标均定义为 0。因此 Precision 或 Recall 分母为零时仅在双方均空定义为 1，单方非空定义为 0。
- 每模型、每随机种子的跨患者患者宏平均分别报告 mean 与样本标准差（ddof=1）；跨患者分布以每患者三种子平均值报告。模型比较先对同一患者的三个配对种子求平均，再计算 Attention U-Net 减 U-Net 的配对患者差值。不得把切片或随机种子当独立患者。

## 配对统计

预先指定双侧 Wilcoxon 符号秩检验，零差值按 Wilcox 规则排除并报告排除数量、有效非零差值数及配对患者数。报告独立患者、配对方向及差值近似对称等检验假设。平均患者差值 95% CI 使用患者对为重采样单位的 percentile bootstrap，重复 10,000 次，随机种子 20261126。未配对/缺失的患者或模型运行显式报告，不补值；没有可用完整配对时统计结果为 `NotRun`。

## 报表和病例选择

`python -m training.generate_reports` 只读取哈希验证通过的真实 split、缓存、训练/验证产物、冻结记录与测试产物。六组模型/种子齐全且覆盖同一测试患者队列后才生成论文表图，否则只写模板和 `NotRun` 清单。合成数据永不生成研究图或研究成绩。

数据源清单保存图表文件 SHA-256、源运行 ID、测试/权重/冻结来源哈希、协议与 split 哈希、指标范围、单位和报表脚本版本。病灶物理体积要求空间单位可信，qform 或 sform 有效，且 affine 与 voxel spacing 一致；否则只报告 voxel 数。最佳/中位/最差患者在完整测试队列上按两模型、三种子患者 Dice 算术平均排序；中位数采用偶数时较低排名，ID 升序打破并列。图像使用固定种子 17，并按最大 WT 面积切片展示；空 GT 使用中间切片。病例图同时展示 FP/FN overlay。

## 后果

研究结论可以复现并检查泄漏、数据缺口及模型差异；但需要所有真实实验运行和完整审计产物才能解锁正式表图。当前仓库未随代码生成 BraTS 训练结果，真实实验成绩仍为 `NotRun`。
